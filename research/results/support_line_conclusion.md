# 결론 — 상승추세 종목이 일시적 하락 시 '자주 지지받는 선'

기간 2019-01-02 ~ 2026-06-23, 전종목 4,079개.
상승추세 = 주봉 MA4>13>26>52 정배열 2주 연속(직전 완성 주봉 기준, 룩어헤드 없음).
지지성공 = 터치일 저가 대비 이후 10거래일 내 고가 +5% 도달.

## 1) 질문에 직접 답: MA10−10% vs BBI−10%

| 선 | 전종목 지지율 (터치수) | KOSPI200 지지율 (터치수) |
|---|---:|---:|
| **BBI −10%** | **88.7% (11,239)** | **89.6% (771)** |
| MA10 −10% | 86.9% (14,594) | 87.1% (1,084) |

→ **BBI −10%가 MA10 −10%보다 약 1.8~2.5%p 높다.** N(5/10/20)·X(3/5/10%)
모든 조합에서 BBI가 일관되게 우위. 단 MA10이 1.3배 더 자주 터치(기회는 많음).

## 2) 그러나 핵심 경고 — '깊이'가 거의 전부다 (기계적 착시)

지지율은 어느 선이든 offset이 깊을수록 단조 증가(−15% > −10% > −5% > 0%).
이는 특정 선의 힘이 아니라 **많이 빠질수록 과매도 → +5% 되돌림이 쉬워지는 기계적 효과**.

baseline(터치 조건 없이 상승추세 아무 날): **+5%/10일 = 71.7%** (하락일만 70.6%).

저가가 '선 대비 얼마나 아래인가'로 버킷팅하면 BBI·MA10이 거의 동일:

| 저가/선 편차 | BBI 반등률 | MA10 반등률 |
|---|---:|---:|
| ≤ −12% | 91.3% | 90.2% |
| −12~−8% | 85.4% | 83.4% |
| −8~−5% | 78.7% | 75.9% |
| −5~−2% | 68.5% | 67.7% |
| **−2~0% (선 바로 위)** | **61.4%** | **60.3%** |
| ≥ +2% | 82.2% | 81.3% |

- 반등률은 **선의 종류가 아니라 선 아래 깊이의 함수**. BBI가 MA10보다 매 버킷 ~1~3%p 높을 뿐.
- **선을 정확히 터치(−2~0%)하는 건 오히려 최악**: 반등률 61% < baseline 71.7%.
  즉 "MA10/BBI에 정확히 닿으면 산다"는 규칙은 무작위 매수보다 나쁘다(가격이 더 흘러내림).
- baseline(72%)을 의미 있게 이기려면 **선 아래 7~8% 이상 언더컷**이 필요.

## 3) 최종 권고

- **단일 최적: BBI −10%** — 지지율 88.7%(전), 89.6%(K200), baseline 대비 +17%p,
  터치 11,239건으로 빈도도 충분. MA10보다 매 조건 우위.
- **기회를 더 원하면 BBI −7%** (84.5%, 터치 22,492건 ≈ 2배).
- **MA5도 BBI와 사실상 동급**(−10% 90.7%)이나 노이즈가 커 BBI를 권장.
- **하지 말 것**: MA10·BBI '정확히'를 지지선으로 쓰는 규칙(0~−2%대는 baseline 이하).
- 시기 의존성·매도 규칙·실거래 비용은 미반영(통계적 빈도 분석). 실매매 적용 시
  별도 포트폴리오 백테스트로 검증 필요.
