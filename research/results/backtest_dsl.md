# DSL (Disparity Support Line) 매매 백테스트 - 파라미터 최적화

## 매매 규칙

```
MA5 = ma(C, 5);  MA10 = ma(C, 10);  MA20 = ma(C, 20);
이평평균 = (MA5 + MA10 + MA20) / 3;
이평분산 = (pow(MA5-이평평균,2) + pow(MA10-이평평균,2) + pow(MA20-이평평균,2)) / 3;
이평이격도 = sqrt(이평분산) / 이평평균 * 100;
스무딩이격 = MA(이평이격도, 스무딩);
DSL = 이평평균 - 승수 * 스무딩이격 * 이평평균 / 100;
```
- **매수**: 종가가 DSL 상향 돌파 (전일 < DSL → 당일 >= DSL)
- **매도**: 종가가 DSL 하향 돌파 (전일 >= DSL → 당일 < DSL)
- **수수료**: 매수 0.015% + 매도 0.015% + 세금 0.18%
- **기간**: 2023 ~ 현재
- **승수 스윕**: [0.5, 1.0, 1.5, 2.0, 2.5, 3.0]
- **스무딩 스윕**: [3, 5, 7, 10, 14, 20]
- **단기 필터**: 보유일 5~20일
