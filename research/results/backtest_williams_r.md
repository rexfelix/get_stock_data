# 윌리엄스 %R 백테스트

## 공식
```
WR = (highest(H,14) - C) / (highest(H,14) - lowest(L,14)) × (-100)
```

## 매매 규칙
- **매수**: WR이 -80을 상향 돌파 (crossup)
- **매도**: WR이 -20을 하향 돌파 (crossdown)
- **체결가**: 크로스 발생일 종가
