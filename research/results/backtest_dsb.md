# DSB (Disparity Squeeze Breakout) 매매 백테스트 - 파라미터 최적화

## 매매 규칙

```
밴드폭 = StdDev(MA5, MA10, MA20, MA60) / Avg(MA5,MA10,MA20,MA60) × 100
스무딩밴드폭 = SMA(밴드폭, 5)
백분위순위 = 60일 롤링 Percentile Rank(스무딩밴드폭)
스퀴즈 = 백분위순위 < squeezePct
```
- **매수**: 전일 스퀴즈 + 당일 확장(순위 상승 + ≥ 임계값) + 종가 > MA20
- **매도 (3가지 중 하나)**:
  1. 트레일링 스톱: 고점 대비 trailPct% 하락
  2. 밴드폭 재수렴: 순위 하락 + 순위 < 50% + 5일 이상 보유
  3. 최대보유일 초과 + 손실 상태
- **수수료**: 매수 0.015% + 매도 0.015% + 세금 0.18%
- **기간**: 2023 ~ 현재

- **squeezePct**: [15, 20, 25, 30, 35]
- **holdDays**: [10, 15, 20, 30]
- **trailPct**: [3, 5, 7, 10]
