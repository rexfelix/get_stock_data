# BBI 상향돌파 매수 / 하향돌파 매도 백테스트

## 규칙

- **BBI = (MA3 + MA6 + MA12 + MA24) / 4** (종가 기준)
- 매수: 전일 종가 ≤ 전일 BBI **AND** 당일 종가 > 당일 BBI (상향돌파) → 당일 종가 매수
- 매도: 전일 종가 ≥ 전일 BBI **AND** 당일 종가 < 당일 BBI (하향돌파) → 당일 종가 전량 매도
- 대상: KOSPI200, 최대 10종목, 1거래당 300만원, 초기자본 3000만원
- 기간: 2023-01-01 ~ 2026-06-04 (MA24 워밍업 2022-01-01부터 로드)
- 수수료: 매수 0.015% + 매도 0.015% + 세금 0.18%
- 슬롯부족 스킵 시그널: 13,187건
