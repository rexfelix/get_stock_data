### 7-3. 단순 RS Top10 전략의 구조적 약점

1. **5일 lookback 노이즈**: 5거래일 수익률은 가격 노이즈 비중 큼 → Top10 매주 큰 폭으로 교체
   (실제 평균 보유 8.0일, 총 3347회 회전)
2. **상대 강도의 함정**: RS Top10은 시점 t-5 ~ t 구간에서 강한 종목 → 모멘텀 reversal 시점에 매수
3. **수수료/세금 누수**: round trip 0.26% × 1.67천 회전 ≈ 누적 ~430%p gross 비용
4. **시장 노출 부족**: 슬롯 비어있는 주는 cash 비중 → 강세장 미참여
5. **분포 비대칭**: 평균 +0.39% / 중위 −0.57%. winner 의존도 매우 큼

### 7-4. 개선 후보 (다음 검토 가능)

- **Lookback 확장**: 5일 → 20일/60일/63일(분기) — 노이즈 감소, 추세 안정
- **시장 필터 추가**: KOSPI 가 MA200 위일 때만 매수 (DOWN 회피)
- **변동성 필터**: RS 상위 중 ATR/변동성 하위 선별 → whipsaw 감소
- **부분 청산**: Top10 탈락만 매도하지 말고 stop-loss / trailing stop 병용
- **풀 크기 분리**: 매수 Top10, 매도 Top30 탈락 — 회전 감소 (hysteresis)
- **거래대금/거래대금 회전율 필터**: 유동성 큰 종목만 (대기업 RS top은 보유 지속성 ↑)

### 7-5. 사용된 RS 공식

- 사용자 정의: `RS = (종목 현재가 / 종목 N일전가) / (지수 현재값 / 지수 N일전값) − 1`
- 본 백테스트 적용: `RS = (1 + r_종목) / (1 + r_지수) − 1`
- 두 표현은 **수학적으로 동일** (가격비 = 1 + 단순수익률):
    `(P_s_t / P_s_{t-N}) / (P_i_t / P_i_{t-N}) − 1 = (1 + r_종목) / (1 + r_지수) − 1`
- 따라서 본 결과는 사용자 정의식 그대로의 백테스트 결과이며, 변환에 의한 의미 차이는 없음.
