# 계단뛰기 (하루 당김) — 종가 매수→다음날 종가 매도 전략

## 변경 사항

- **조건 하루 당김**: 모든 봉 인덱스 -1 (원본 bar 2→1, 1→0), 원본 bar(0) 참조 조건 모두 제거
- 제거: 조건 4, 6, 8, 12, 13, 16, 17
- 새 논리식: `1 && 2 && 3 && (5 || (7 && 9)) && 10 && 11 && 14 && 15`

**새 조건**:

- 1) open(1) < close(1) — 어제 양봉
- 2) open(0) > close(1) — 오늘 시가가 어제 종가 위에서 출발
- 3) low(0) > (open(1)+close(1))/2 — 오늘 저가가 어제 캔들 중앙선 위
- Branch A: 5) open(0) < close(0) — 오늘 양봉
- Branch B: 7) open(0) > close(0) AND 9) volume(1) > volume(0) — 오늘 음봉 + 거래량 감소
- 10) close(1) > ma5(1), 11) close(0) > ma5(0)
- 14) 시가총액 ≥ 3000억, 15) close(0) ≥ 2000원

**매매**:

- 시그널 당일(t=0) 종가에 매수
- 다음날(t=+1) 종가에 매도 (1-day hold, close-to-close)
