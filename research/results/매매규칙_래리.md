# 스윙 돌파 매매 규칙 (최종)

## 용어 정의

- **단기저점**: 앞뒤날 저가보다 가운데날 저가가 더 낮은 날 (다음날 종가 확정 시 인식)
- **단기고점**: 앞뒤날 고가보다 가운데날 고가가 더 높은 날 (다음날 종가 확정 시 인식)

## 매수 조건

### 1) 돌파 시그널
1. 단기저점이 확정되면, **저점 캔들의 고가**를 매수 트리거로 설정
2. 이후 주가가 트리거를 **상향 돌파하는 순간** 즉시 매수
3. 체결가 = 저점 캔들의 고가 (지정가 매수)
4. 양봉/음봉 무관하게 홀드 (당일 음봉 청산 하지 않음)

### 2) 종목 필터 (매수 전 사전 확인)
- **20일 평균 거래대금 ≥ 200억원**: 전일까지 20일 평균 기준 (당일 제외, 사전에 확인 가능)
- **20일 이격도 > 97**: 과매도 종목 제외 (이격도 ≤ 97이면 매수 안 함)
- **종가 > 20일 이동평균선**: 추세 방향으로만 매수

### 3) 종목수 제한
- **최대 동시 보유: 10종목**
- 빈 슬롯이 있을 때만 신규 매수
- 돌파 순서대로 매수 (먼저 돌파하는 종목부터)

## 매도

### 1) 고점저가 이탈 매도
- 매수 후 단기고점이 확정되면, **고점 캔들의 저가**를 매도 트리거로 설정
- 이후 주가가 트리거를 **하향 돌파하면** 매도
- 체결가 = 고점 캔들의 저가

### 2) 손절
- 매수일(기준봉)의 **저가를 하향 돌파하면** 즉시 손절
- 체결가 = 매수일 저가

## 매도 우선순위

```
매일 체크:
  1) 손절선(매수일 저가) 이탈 → 즉시 손절
  2) 고점저가 이탈 → 매도
```

## 자금 배분

- 당일 신규 매수 종목수로 보유 현금을 균등 배분
- 한 종목당 투자금 = 현금 / 신규 매수 종목수
- 수익 발생 시 수익금의 50%는 저축, 50%는 재투자

## 추천 대상

- **KOSPI200 종목**

- MA20 위 + 이격도 97 + 거래대금 200억 조합이 이미 추세 필터링을 충분히 수행

## 매매 흐름도

```
사전 필터: 20일 평균 거래대금 ≥ 200억? → NO → 대상 제외
    ↓ YES
단기저점 확정
    ↓
필터 확인: 이격도 > 97? MA20 위? 보유 10종목 미만?
    ├── NO → 매수 안 함
    └── YES ↓
매수 트리거 설정 (저점 캔들 고가)
    ↓
상향 돌파 → 매수 (양봉/음봉 무관 홀드, 돌파 순서대로)
    ↓
매일 체크
    ├── 매수일 저가 이탈 → 손절
    └── 단기고점 확정 → 고점 저가 이탈 시 매도
            ↓
        수익 발생 → 수익금 50% 저축 + 50% 재투자
```

## 주의사항

- 당일 음봉 청산은 하지 않음 (포트폴리오 시뮬 결과 홀드가 압도적 우위)
- 이격도 ≤ 95, MA20 아래 종목은 반드시 제외 (과매도 돌파는 실패율 높음)
- 시장 전체 급락 시 다수 종목 동시 손절 가능
- 갭다운 시 손절가보다 낮은 가격에 체결될 수 있음 (슬리피지)
- 시뮬 수치는 이상적 조건이며, 실전은 보수적으로 기대할 것

## 영웅문 수식

### 매수 조건검색

```
// 단기저점 돌파 + 이격도 > 97 + MA20 위 + 거래대금 200억 이상
A := ref(low,2) > ref(low,1) and ref(low,1) < low;
B := high >= ref(high,1);
C := close / ma(close, 20) * 100 > 97;
D := close > ma(close, 20);
E := ma(close * volume, 20) / 100000000 >= 200;
A and B and C and D and E
```

### 매도 조건검색

```
A := ref(high,2) < ref(high,1) and ref(high,1) > high;
B := low <= ref(low,1);
A and B
```
