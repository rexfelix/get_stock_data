# 스윙 돌파 매매 규칙 (최종)

## 용어 정의

- **단기저점**: 앞뒤날 저가보다 가운데날 저가가 더 낮은 날 (다음날 종가 확정 시 인식)
- **단기고점**: 앞뒤날 고가보다 가운데날 고가가 더 높은 날 (다음날 종가 확정 시 인식)

## 매수

1. 단기저점이 확정되면, **저점 캔들의 고가**를 매수 트리거로 설정
2. 이후 주가가 트리거를 **상향 돌파하는 순간** 즉시 매수
3. 체결가 = 저점 캔들의 고가 (지정가 매수)
4. 양봉/음봉 무관하게 홀드 (당일 음봉 청산 하지 않음)

## 매도

### 1) 고점저가 이탈 매도
- 매수 후 단기고점이 확정되면, **고점 캔들의 저가**를 매도 트리거로 설정
- 이후 주가가 트리거를 **하향 돌파하면** 매도
- 체결가 = 고점 캔들의 저가

### 2) 손절
- 매수일(기준봉)의 **저가를 하향 돌파하면** 즉시 손절
- 체결가 = 매수일 저가

## 매도 우선순위

```
매일 체크:
  1) 손절선(매수일 저가) 이탈 → 즉시 손절
  2) 고점저가 이탈 → 매도
```

## 자금 배분

- 당일 신규 매수 종목수로 보유 현금을 균등 배분
- 한 종목당 투자금 = 현금 / 신규 매수 종목수

## 매매 흐름도

```
단기저점 확정
    ↓
매수 트리거 설정 (저점 캔들 고가)
    ↓
상향 돌파 → 매수 (양봉/음봉 무관 홀드)
    ↓
매일 체크
    ├── 매수일 저가 이탈 → 손절
    └── 단기고점 확정 → 고점 저가 이탈 시 매도
```

## 주의사항

- 당일 음봉 청산은 하지 않음 (포트폴리오 시뮬 결과 홀드가 압도적 우위)
- 개별 거래 분석에서는 양봉이 유리하나, 복리 효과로 필터 없이 홀드가 최적
- 시장 전체 급락 시 다수 종목 동시 손절 가능 (MDD -12% 수준)
- 갭다운 시 손절가보다 낮은 가격에 체결될 수 있음 (슬리피지)

## 영웅문 수식

### 매수 조건검색

```
A := ref(low,2) > ref(low,1) and ref(low,1) < low;
B := high >= ref(high,1);
A and B
```

### 매도 조건검색

```
A := ref(high,2) < ref(high,1) and ref(high,1) > high;
B := low <= ref(low,1);
A and B
```
