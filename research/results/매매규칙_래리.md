# 래리 윌리엄스 MTL/MTH 스윙 매매 규칙

자동매매 시스템 구현용 거래 규칙 정의서

## 용어 정의

- **STL (단기저점)**: Low[i] < Low[i-1] AND Low[i] < Low[i+1]
  - 확정 시점: i+1일 종가 확정 시
- **STH (단기고점)**: High[i] > High[i-1] AND High[i] > High[i+1]
  - 확정 시점: i+1일 종가 확정 시
- **MTL (중기저점)**: 연속된 3개 STL(A, B, C) 중 Low[B] < Low[A] AND Low[B] < Low[C]
  - 확정 시점: STL[C]가 확정되는 날
- **MTH (중기고점)**: 연속된 3개 STH(A, B, C) 중 High[B] > High[A] AND High[B] > High[C]
  - 확정 시점: STH[C]가 확정되는 날
- **R**: 진입가 - 손절가 (1거래의 리스크 금액 단위)

## 대상 종목

- **KOSPI200 구성종목**

## 진입 조건

아래 3가지를 **모두** 만족할 때 매수:

1. 가장 최근 확정된 MTL이 존재
2. 그 MTL **이후** 가장 최근 확정된 MTH가 존재
3. 당일 **종가**가 MTH 캔들의 고가를 **상향 돌파** (전일 종가 <= MTH 고가 AND 당일 종가 > MTH 고가)

### 매수가

- 당일 종가

### 진입 필터 (R% >= 7%)

- R% = (진입가 - 손절가) / 진입가 × 100
- **R% < 7%이면 진입하지 않음**
- 근거: R% >= 7% 구간이 평균수익 +3.85%, 총손익 3,812만원으로 최상위

### 포지션 제한

- 최대 동시 보유: **10종목**
- 빈 슬롯이 없으면 신규 진입 불가
- 1거래당 투자금: **300만원** (고정)

## 청산 규칙

### 1. 손절 (최우선)

- **조건**: 당일 저가 <= 손절가
- **손절가**: 진입 시점 가장 최근 확정된 STL의 저가 - 1원
- **체결가**: 손절가 (지정가)
- 진입 후 고정, 변경하지 않음

### 2. 1차 익절 (2R)

- **조건**: 당일 고가 >= 진입가 + 2R
- **체결가**: 진입가 + 2R (지정가)
- **수량**: 보유 수량의 **50%** 청산
- 1회만 실행

### 3. 최종 청산 (트레일링 STL 스톱)

- **조건**: 당일 저가 <= 가장 최근 확정된 STL의 저가
- **체결가**: 해당 STL의 저가 (지정가)
- **수량**: 잔여 전량 청산
- 대상 STL: 진입일 이후 새로 확정된 STL만 해당
- STL이 새로 확정될 때마다 스톱 레벨이 갱신됨 (트레일링)

### 청산 우선순위

```
매일 체크:
  1) 손절가 이탈 → 즉시 손절 (전량)
  2) 2R 도달 → 50% 청산 (미실행 시)
  3) 최근 STL 저가 이탈 → 잔량 전량 청산
```

## 매매 흐름도

```
[시그널 탐지]
  매일 장 마감 후:
  1. 오늘 확정된 STL/STH 업데이트
  2. MTL/MTH 리스트 갱신
  3. 진입 조건 체크:
     MTL 존재? → 이후 MTH 존재? → 종가 > MTH 고가?
     → YES: 후보 종목 리스트에 추가

[진입 필터]
  후보 종목 중:
  - KOSPI200 구성종목인가?
  - R% >= 7%인가?
  - 빈 슬롯이 있는가?
  → 모두 YES: 당일 종가에 300만원 매수

[보유 중 매일 체크]
  장중 실시간:
  1. 저가 <= 손절가? → 손절 (전량)
  2. 고가 >= 진입가+2R? → 50% 익절
  3. 저가 <= 최근 STL 저가? → 전량 청산
```

## 주의사항

- 중기저점(MTL)은 확정이 늦음 (STL 3개 필요 → 수일~수주 지연)
- 갭다운 시 손절가보다 낮은 가격에 체결 가능 (슬리피지)
- 1거래당 300만원 고정이므로 복리 효과 없음
- 시장 전체 급락 시 다수 종목 동시 손절 가능
