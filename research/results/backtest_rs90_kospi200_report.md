# RS>=90 & KOSPI200 조건부 보유 전략 백테스트 리포트

## 1. 전략 개요

| 항목 | 내용 |
|------|------|
| 전략명 | RS>=90 & KOSPI200 조건부 보유 |
| 핵심 아이디어 | 상대강도(RS) 상위 10% 이내 대형주만 보유, 조건 이탈 시 즉시 교체 |
| 유니버스 | KOSPI200 구성종목 (200종목) |
| 매수 조건 | RS Rating >= 90 (상위 ~10%) AND KOSPI200 편입 |
| 매도 조건 | RS Rating < 90 으로 하락 시 매도 |
| 리밸런싱 | 매주 첫 영업일 (총 66회) |
| 포지션 구성 | 동일가중 (매주 포트 가치를 N등분) |
| 기간 | 2025-01-02 ~ 2026-03-25 (약 15개월) |
| 초기자본 | 1억원 |
| 수수료 | 매수 0.015% / 매도 0.015% / 세금 0.23% |

### RS Rating 계산 방식 (윌리엄 오닐)
```
RS_raw = 2*(최근분기 수익률 - 지수) + (2분기전 - 지수) + (3분기전 - 지수) + (4분기전 - 지수)
RS_rating = percentile_rank(RS_raw) → 1~99
```
- 비교 지수: KOSPI (^KS11)
- 1분기 = 63 영업일 (약 3개월)
- 최근 분기에 2배 가중치 부여

## 7. 고찰 및 시사점

### 전략의 강점
1. **단순하고 체계적**: RS>=90 AND KOSPI200 단 두 가지 조건만으로 운용
2. **추세 추종 효과**: RS가 높은 종목 = 이미 상승 추세 → 모멘텀 프리미엄 획득
3. **자동 손절**: RS가 90 미만으로 떨어지면 자동 매도 → 하락 추세 종목 조기 탈출
4. **대형주 필터**: KOSPI200이므로 유동성 리스크 최소화, 거래 실행 용이
5. **분산 투자**: 평균 29종목 동시 보유 → 개별 종목 리스크 분산

### 전략의 약점 / 유의점
1. **후행 지표**: RS는 과거 1년 수익률 기반 → 이미 많이 오른 후 매수하는 구조
2. **팻테일 의존**: 소수 대형 승자에 수익 집중, 승률 47%로 심리적 부담
3. **관세 쇼크 같은 급락**: 주간 리밸런싱으로는 일중 급락 대응 불가 (MDD -18%)
4. **KOSPI200 편입 변동**: 현재 KOSPI200 목록 기준으로 과거를 역추적 (생존자 편향 일부 존재)
5. **거래 비용**: 66회 리밸런싱 × 평균 3~5종목 교체 → 연간 상당한 거래 비용 발생
6. **시장 환경 의존**: 2025년은 강세장 — 약세장에서의 성과 검증 필요

### 개선 가능 방향
- **리밸런싱 주기 조절**: 월간 리밸런싱으로 거래 비용 절감
- **RS 임계값 조절**: RS>=80 또는 RS>=95로 변형 비교
- **추가 필터**: Grade(A/B) 재무 건전성 필터 결합
- **손절 강화**: 주간 RS 체크 외에 일중 -10% 손절선 추가
- **약세장 테스트**: 2024년 데이터 포함하여 하락장 성과 확인

## 8. 결론

> **RS>=90 & KOSPI200 조건부 보유 전략은 2025년 초~2026년 3월까지
> KOSPI 대비 +52%p 초과수익을 달성했다.**
>
> 핵심 원리는 **모멘텀 효과**(강한 종목이 계속 강하다)이며,
> KOSPI200 필터로 유동성을 확보하고, RS 하락 시 자동 매도로 추세 이탈 종목을 걸러낸다.
>
> 다만 승률이 낮고 소수 대형 승자에 의존하는 구조이므로,
> **장기간 일관되게 규칙을 따르는 것**이 전략 성공의 핵심 조건이다.
