# 급락주 매매 규칙

급락 신호: 20일 이동평균에 대한 종가 이격도 90% 이하(즉, 20 이평 아래로 10% 이상 떨어진 종목)
극등 신호: 20일 이동평균 이격도120 % 이상 (즉 20일 이평에서 위로 20% 이상 떨어진 종목)

- 매수 : 급락 신호 시 + 음봉이면서 + 전일 거래량 보다 큰 거래량이면 '기준봉'으로 삼는다 => 이후 기준봉의 시가를 돌파할 때 매수. 
     => 매수하지 못 하고 기준봉 조건을 만족하는 다른 봉이 나타나면 기준봉을 갱신한다. => 기준봉을 돌파하지 못 한채 20이평선 위로 가격이 올라가면 기준봉 자격을 취소

- 매도 : = 급등 신호 뜨거나 
        = 종가가 20일선 위로 올라 간 후 5일선을 종가로 이탈하면 매도

- 손절 : 매수한 봉 저가를 종가로 이탈하면 손절
