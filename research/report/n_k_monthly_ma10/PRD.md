# PRD - 1500억 (N,K) + 월봉 MA10 위 필터 매트릭스

## 프로젝트 목적

이전 검증에서 발견된 (15,3) **시기 의존성** (2024+ 강세장 한정 우위, 2019~2023 Calmar 0.29) 을 극복하기 위해 **월봉 MA10 위 = 장기 강세 추세** 필터를 추가한다. 일봉 MA 필터는 whipsaw 폭락 (3회 검증, 79~95%) 이었지만, **월봉 MA10 은 stable한 장기 지표** 로 변동성 낮아 다른 메커니즘 가능.

## 해결하려는 문제

- **시기 의존성**: (15,3) 2019~2023 Calmar 0.29 (vs 2024~2026 41.88, -99.3%) — 약세/혼조장에서 무력
- **regime 적응 필요**: 시장이 상승 추세일 때만 매수, 하락/횡보 시 회피
- **월봉 MA10 의 stable 특성**: 일봉 정배열·MA20 5일 상승 같은 단기 필터(폭락)와 달리, 월봉은 한 달 단위 갱신이라 변동 매우 적음 → whipsaw 위험 낮음

## ⚠️ 사전 위험 고지

memory `feedback_simple_is_better` (3회 검증 폭락):
- 일봉 정배열, MA20 5일 상승 → -84~95% Calmar 폭락
- 본 검증은 **월봉 MA10** = 매도 LIST_EXIT 와 동기화 가능성 매우 낮음 (월별 갱신)
- 그러나 가설일 뿐, 실제 검증 필요

## 범위 (In-Scope)

### 매수 조건
- 1500억 N/N 만족 (N별 다름)
- **추가**: T일 close > 직전 완료 월의 월봉 MA10
  - 월봉 close = 매월 마지막 거래일 종가
  - 월봉 MA10 = 직전 완료 10개월의 월봉 close 단순 이평
  - 예: 2024-03-15 매수 신호 → 2023-05~2024-02의 10개월 월봉 close 평균과 비교
- 통과 종목 amount 상위 K개 매수

### 매도 규칙
- LIST_EXIT (1500억 N/N 깨지면 매도) — 베이스와 동일

## 기능 요구사항

### F1. 월봉 MA10 계산

`compute_monthly_ma10(daily_data)` :
- 각 ticker 의 daily df 에서 매월 마지막 거래일 close 추출
- 10개월 단순 이평 계산
- 일별로 매핑: 그날의 직전 완료 월의 MA10 값 → daily df 에 `monthly_ma10` 컬럼 추가
- MA10 미계산 구간 (초기 9개월) NaN

### F2. 월봉 MA10 위 필터

`apply_monthly_ma10_filter(signals, daily_data)`:
- 각 (date, ticker) 에서 daily_data[ticker] 의 그날 close 와 monthly_ma10 비교
- close > monthly_ma10 만 통과
- NaN 시 불통

### F3. 매트릭스 백테스트

12 시나리오 각각 run_backtest + equity_real_k

### F4. 분석 + 결론

- 시기 의존성 극복 여부 판정 (2019~2023 Calmar 변화)
- 강세장 영향 평가 (2024~2026 Calmar 변화)
