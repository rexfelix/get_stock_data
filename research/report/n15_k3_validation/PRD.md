# PRD - (N=15, K=3) 실전 운영성 검증

## 프로젝트 목적

1500억 N×K 매트릭스에서 Calmar 1위인 **(N=15, K=3)** 조합이 백테스트 수치만 좋고 실전 운영에는 부적합한지(거래 부족·집중 리스크) 정량 검증한다. 기존 추천(5/5/5)과의 trade-off를 데이터로 명확히 한다.

## 해결하려는 문제

- (15,3)은 Calmar 41.88 / CAGR +105.7% / MDD -2.52% 로 매트릭스 1위지만, 거래수 3.3년에 17건뿐
- "1 종목 비중 33% × 거래정지·악재 직격 시 자본 -16.7% 충격"이라는 운영 리스크 의심이 있음
- 거래 분포가 특정 시기·특정 종목에 쏠려 있다면 검증 가치 약화
- 위 의심을 검증하지 않은 상태로 (15,3) 채택은 위험

## 범위 (In-Scope)

- **분석 1. 거래 분포 (시간/종목)**
  - 1500억 N=15/K=3 백테스트 17건 거래의 연도별·월별 분포
  - 매수 종목 다양성 (고유 종목 수, 동일 종목 재거래 횟수)
  - 가장 긴 무거래 구간 (No-Trade Gap) 측정
- **분석 2. 종목별 손익 분포**
  - 각 거래의 보유 기간 / 종목별 누적 손익 / 최대 단일 거래 손실
  - Top winner / worst loser 종목 식별
- **분석 3. Stress Test (블랙스완)**
  - 동시보유 3종목 중 1종목 거래정지 가정 (sell_price = buy_price × {0%, 30%, 50% 회수}) 시나리오
  - 각 시나리오에서 전체 CAGR / MDD / Calmar 재계산
  - 시뮬레이션: 17건 각각에 대해 한 번씩 -50% 직격 가정 → 전체 분포 (worst-case envelope)
- **분석 4. (5,5) 와 직접 비교**
  - 동일 기간 (5,5) 거래 분포 / 종목 다양성 / 무거래 구간 비교
  - 어느 쪽이 운영 안정성에서 우월한지 정량 평가

## 비범위 (Out-of-Scope)

- 매매 규칙 변경
- 새 임계치(2000억/5000억) 추가
- 모의투자 슬리피지 측정 (별도 task)
- KOSDAQ150 확장

## 사용자 시나리오

투자자(PO)는:
- "거래 17건이 3.3년 동안 어떻게 분포돼 있나? 1년에 5건이면 1년 통째로 안 거래되는 해도 있나?"
- "17건 거래가 3~4 종목에 쏠려있으면 사실상 단일 종목 베팅 아닌가?"
- "삼성전자처럼 큰 종목이라 거래정지는 없겠지만, 갑작스런 -30% 갭다운(예: 회계 이슈) 시 자본 충격은?"
- "(5,5)와 비교해서 운영 측면에서 정말 (15,3)이 더 좋은가?"

## 기능 요구사항

### F1. (15,3) 거래 데이터 추출
- `backtest_n_k_matrix.py` 와 동일 환경에서 N=15/K=3 단독 실행, trades 리스트 확보
- (5,5) 도 동일하게 추출 (비교용)

### F2. 거래 분포 분석
- 연도별/월별 거래수 표
- 매수 종목 unique 카운트, 종목별 거래 횟수 Top
- 가장 긴 무거래 구간(buy_date 사이 최대 gap) 일자/길이

### F3. 종목별 손익 분석
- 거래별 보유일/수익률 분포 (히스토그램 통계)
- Top 5 / Bottom 5 종목 (누적 net_ret)
- 단일 거래 max loss / max gain

### F4. Stress Test
- 시나리오 A: 17건 각각 한 번씩 sell_price를 buy_price×0.5(즉 -50%)로 강제 → 전체 stats 재계산
- 시나리오 B: 한 거래만 sell_price=0 (거래정지 시나리오, 자본 1/3 전손) → CAGR/MDD 영향
- 결과: worst-case Calmar / 평균 충격 / 분포

### F5. (5,5) 비교
- 거래수, 종목 다양성, 무거래 구간을 같은 형식으로 산출 후 (15,3) vs (5,5) 비교 표

### F6. 결과 리포트
- `results/backtest_n15_k3_validation.md` 생성
- 분석 1~5 모든 결과 포함, 종합 결론

## 비기능 요구사항

- 단일 스크립트 실행으로 분석 완료
- 실행 시간 5분 이내 (이미 캐시된 데이터 활용)
- 결과는 결정론적 (동일 데이터/시드 기준)
