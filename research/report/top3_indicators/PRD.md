# PRD - Top 3 지표 비교 백테스트

## 프로젝트 목적

거래대금/시가총액을 기준으로 한 **당일 상위 3개 종목 매수 전략**의 수익성을 다양한 매도 규칙과 조합하여 비교 검증한다.

## 해결하려는 문제

- 단순 거래대금 상위 종목 매수 vs 시가총액 상위 종목 매수 vs 거래회전율(거래대금/시가총액) 상위 매수 — 어떤 지표가 가장 효과적인가?
- 매도 규칙(리스트 이탈, MA5, MA20, 고정 보유) 중 어떤 것이 수익률을 극대화하는가?

## 범위 (In-Scope)

- **대상**: KOSPI200 종목 (kospi200_members 200종목, 2026-04-16 기준)
- **기간**: 2023-01-01 ~ 현재
- **지표 3종**:
  1. 거래대금 단독 (amount)
  2. 시가총액 단독 (mcap, ka10001로 수집)
  3. 거래대금/시가총액 비율 (turnover ratio)
- **매도 규칙 4종**:
  1. 리스트 이탈 (다음날 Top3에서 빠지면 매도)
  2. MA5 이탈 (종가 < MA5 → 매도)
  3. MA20 이탈 (종가 < MA20 → 매도)
  4. N일 보유 후 매도 (5/10/20일)
- **조합 수**: 3 지표 × 6 매도규칙(4 + N=5/10/20) = 18 조합
- **수수료**: 매수 0.015% + 매도 0.015% + 세금 0.18% (기존 백테스트와 동일)
- **포트폴리오**: 매수 시점 자본의 1/3씩 균등 매수 (Top3)

## 비범위 (Out-of-Scope)

- 종목 스크리닝 (KOSPI200 외 제외)
- 중간 추가매수, 분할매도
- 슬리피지, 일중 가격 변동 시뮬레이션
- 시가총액 정밀 시계열(상장주식수 변동) — 현재 mcap/close 비율로 상장주식수 추정 후 historical mcap 계산

## 사용자 시나리오

투자자(PO)는 다음 의문을 가진다:
- "거래대금 폭증 종목을 무작정 사면 되나?"
- "시가총액 상위주(삼성전자, SK하이닉스 등) Buy & Hold가 더 낫나?"
- "회전율 높은 종목이 모멘텀이 강한가?"

본 백테스트는 위 질문에 대한 정량적 답을 제공한다.

## 기능 요구사항

### F1. 시가총액 데이터 수집
- 키움 ka10001 (주식기본정보요청)으로 KOSPI200 200종목의 현재 시가총액(mac) 수집
- 결과를 `report/top3_indicators/market_cap_snapshot.csv`로 저장
- 상장주식수 = mcap / close (수집일 종가 기준) → 시계열 mcap = close[d] × 상장주식수

### F2. 백테스트 엔진
- 일별로 KOSPI200 종목의 지표값 계산
- Top 3 추출 → 다음날 시가 매수
- 각 매도 규칙 적용 → 매도가 결정 (리스트 이탈/MA 이탈은 종가, 고정 보유는 N일 후 종가)
- 동시 보유 가능, 종목당 1포지션만 보유

### F3. 결과 리포트
- 18 조합 × (전체기간 + 연도별) 통계 생성
- `results/backtest_top3_indicators.md`에 저장

## 비기능 요구사항

- 단일 스크립트 실행으로 전체 백테스트 완료
- 데이터 수집 단계 분리 (`fetch_market_cap.py` 별도)
- 실행 시간 10분 이내

## 완료 기준 (Definition of Done)

- [ ] 시가총액 snapshot 수집 완료 (200종목)
- [ ] 18 조합 모든 백테스트 실행 성공
- [ ] 종합 비교 표(누적수익률, 승률, MDD, 손익비) 리포트 생성
- [ ] Reviewer 승인 (`APPROVED`)

## 테스트 관점 핵심 검증 항목

- 시가총액 단독 Top3 = 항상 삼성전자/SK하이닉스/LG에너지솔루션 부근 → 결과는 KOSPI200 시총 가중 인덱스와 유사해야 함
- 거래대금 단독 Top3 = 일별 변동성 큼, 모멘텀 종목 잡힘
- 거래회전율 Top3 = 작은 종목 위주(KOSPI200이라 영향 제한)

## 제약사항

- 데이터 한계: 상장주식수 시계열 미보유 → 단일 시점 비율 사용 (split/유상증자 영향 무시)
- KOSPI200 멤버십 시계열 미보유 → 현재 200종목 기준으로 백테스트 (forward-looking bias 존재)

## 가정사항

- KOSPI200 대형주는 상장주식수 변동 미미하다고 가정
- 시가총액 ranking은 일별로 거의 변동 없으나, 거래대금/회전율은 일별 변동성 높음
