# DSL : Disparity Support Line
MA5 = ma(C, 5);
MA10 = ma(C, 10);
MA20 = ma(C, 20);

이평평균 = (MA5 + MA10 + MA20) / 3;
이평분산 = (pow(MA5 - 이평평균,2) + pow(MA10 - 이평평균,2) +
 pow(MA20 - 이평평균,2)) / 3;
이평이격도 = (제곱근(이평분산) / 이평평균) * 100;
스무딩이격 = 평균(이평이격도, 스무딩);
DSL = 이평평균 - 승수 * 스무딩이격 * 이평평균 / 100;

- 변수: 승수, 스무딩
- 매수 : 주가가 DSL 상향 돌파
- 매도 : 주가가 DSL 하향 돌파
